# Summary
On 2026-10-21 frontend page loads took 6 s and recommendation timed out. product-catalog latency was high because queries waited on locks in postgresql.

# Root cause
A batch price migration held long locks on the products table in postgresql. The root cause was postgresql lock contention.

# Resolution
We cancelled the migration query and reran it in small batches at night.
