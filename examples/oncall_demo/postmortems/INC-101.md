# Summary
On 2026-09-03 the checkout error rate rose to 30% for 42 minutes. The payment service rejected charges after a config change set a wrong gateway API endpoint. Users saw "payment failed" at checkout.

# Root cause
A config change in payment pointed to the gateway's sandbox endpoint. Root cause was in payment.

# Resolution
We rolled back the payment config to the previous version. Error rate returned to normal within 3 minutes.

# Follow-ups
Add config validation to the payment deploy pipeline.
