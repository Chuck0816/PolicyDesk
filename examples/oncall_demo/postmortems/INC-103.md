# Summary
On 2026-10-02 order events piled up in Kafka. The fraud-detection consumer lag reached 250000 messages and orders waited 40 minutes for fraud approval. Checkout itself stayed healthy.

# Root cause
fraud-detection ran out of memory (OOM) after a model update doubled its memory use, so consumers kept restarting. Root cause was in fraud-detection.

# Resolution
We raised the fraud-detection memory limit and scaled fraud-detection consumers from 2 to 4 replicas. The lag cleared in 20 minutes.
