# Summary
On 2026-09-17 checkout p99 latency rose to 4 s and cart requests timed out for 25 minutes. The valkey-cart connection pool was exhausted: connected clients reached the 1000 limit.

# Root cause
A cart release leaked one valkey-cart connection per failed request. The root cause was in cart, which exhausted valkey-cart connections.

# Resolution
We restarted the cart pods to release connections and then rolled back the cart release.

# Follow-ups
Alert on valkey-cart connected clients (CartCacheConnectionsHigh).
