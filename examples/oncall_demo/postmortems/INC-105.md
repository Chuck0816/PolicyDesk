# Summary
On 2026-11-05 checkout p99 latency rose to 3 s and payment error rate rose to 8%. The card gateway was slow, so payment calls timed out.

# Root cause
The external card gateway had a partial outage. Root cause was in payment's gateway dependency; checkout was only affected.

# Resolution
We enabled the fallback gateway flag in payment. Latency recovered in 5 minutes.
